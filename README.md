## ◆ Sobre o projeto

O Sistema de Chamados IFRN é uma aplicação web desenvolvida para facilitar o registro e o gerenciamento de chamados de manutenção, permitindo acompanhar as solicitações e visualizar suas respectivas informações.

O projeto foi desenvolvido como atividade acadêmica do curso Técnico Integrado em Informática do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Norte (IFRN).

## ◆ Funcionalidades

- Listagem de chamados.
- Busca de chamados.
- Filtragem por status.
- Abertura de novos chamados.
- Visualização dos detalhes de cada chamado.
- Edição de chamados.
- Resolução de chamados.
- Exclusão de chamados com confirmação.
- Exibição de mensagens de carregamento, erro e lista vazia.

## ◆ Tecnologias utilizadas

| Tecnologia | Finalidade |

| React | Construção da interface |
| Vite | Ferramenta de desenvolvimento |
| JavaScript | Lógica da aplicação |
| React Router DOM | Navegação entre páginas |
| Axios | Comunicação com a API |
| CSS | Estilização da interface |

## ◆ Como executar o projeto

### 1. Pré-requisitos

É necessário ter o Node.js e o npm instalados no computador.

### 2. Clone o repositório

```bash
git clone https://github.com/Vitoria-Cristina7/sistema-de-chamados.git
```

### 3. Entre na pasta do projeto

```bash
cd sistema-de-chamados
```

### 4. Instale as dependências

```bash
npm install
```

### 5. Inicie a aplicação

```bash
npm run dev
```

Após executar o comando, acesse no navegador o endereço local apresentado no terminal.

## ◆ API

O sistema utiliza uma API externa para consultar e gerenciar os chamados.

**Endereço da API:**

https://api-chamados.jefersonqueiroga.com.br

A comunicação com a API é realizada utilizando Axios, com o envio da chave de acesso necessária nas requisições.

**Importante:** a chave de acesso à API não deve ser publicada no repositório. Utilize uma configuração segura para armazenar informações sensíveis.

## ◆ Objetivo acadêmico

Este projeto tem como objetivo aplicar os conhecimentos adquiridos na disciplina de Programação para Internet, utilizando React para desenvolver uma interface web integrada a uma API.
